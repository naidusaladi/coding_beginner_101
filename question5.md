# Find highest number 

## question
Give a string (s) find if it is valid length or not. if length greater than or equals to 4 and less than or equals to 10 then it is a valid string else it is invalid string.  

## example

input 1:
s="abcd"
output: valid

input 2:
s= "abc"
output: invalid

input 3:
s= "abcdefgh"
output: valid

input 4:
s= "aaaaaaaaaaa"
output: invalid
