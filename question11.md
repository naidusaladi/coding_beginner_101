# Find highest number 

## question
Give a array(arr) of strings print all the strings starting with "b".  

## example

input 1:
arr=["bat","ball","ban","apple"]
output: 
    bat
    ball
    ban

input 2:
arr= ["cat"]
output: None

input 3:
arr= ["dog","mat","hat","bunny"]
output: bunny

input 4:
arr= []
output: None
