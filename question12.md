# Find highest number 

## question
Give a array(arr) of strings print the longest string.  

## example

input 1:
arr=["a","aa","aaa"]
output:aaa

input 2:
arr= ["bit","byte","million"]
output: million

input 3:
arr= ["apple","bat","cat"]
output: apple

input 4:
arr= ["a","a"]
output: a

input 5:
arr=[]
output: None
